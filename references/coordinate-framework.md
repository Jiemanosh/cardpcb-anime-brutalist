# 坐标框架（Coordinate Framework）

## 三个坐标系

| 坐标系 | 单位 | 说明 |
|--------|------|------|
| 设计稿（SVG / 渲染 PNG） | mm，y **向下**，原点左上 | 人眼直觉；底视图 |
| EDA 局部坐标 | **0.1mil**（即 1/10 mil） | `get()` 返回的复杂多边形点；`sx = BW_mm*3.937 - mm_x*3.937` 这类 |
| EDA 放置坐标 / `create` 入参 | **mil**（1mil = 0.0254mm） | `pcb_PrimitiveImage.create(x,y,cp,layer,w,h)` 的 x/y/w/h |

换算链：1mm = 39.37mil = 393.7（0.1mil）。即 mm→0.1mil 乘 `3.937`，0.1mil→mil 乘 `10`。

## 板尺寸常量

本项目 `BW=91mm, BH=60mm`：
- `X_off = 91 * 3.937 = 358.2677`（0.1mil）
- `Y_off = 60 * 3.937 = 236.2205`（0.1mil）

通用：`X_off = BW_mm*3.937`，`Y_off = BH_mm*3.937`。

## 底视图（B 面）映射

设计稿在"底视、y 向下"帧，mask 包围盒 `(mx0,mx1,my0,my1)`（mm，y 向下）。

```
sx0 = X_off - mx1*3.937      # 用 mx1 算 sx0 → 实现 X 镜像
sx1 = X_off - mx0*3.937
sy0 = -Y_off + my0*3.937     # 注意负号
sy1 = -Y_off + my1*3.937

X_P = sx1*10                 # 右边缘（mil）
W_P = (sx1 - sx0)*10         # 宽（mil）
Y_P = -sy0*10                # 顶边缘（mil）  ← 即"Y 取反"的来源
H_P = (sy1 - sy0)*10         # 高（mil）
```

`create(X_P, Y_P, cp, layer, W_P, H_P)` 把复杂多边形**自身包围盒**线性拉伸进
`[X_P-W_P, X_P] × [Y_P-H_P, Y_P]`：

- X：`[sx0*10, sx1*10]` —— 因为 `X_P-W_P = sx1*10 - (sx1-sx0)*10 = sx0*10` ✓
- Y：`[Y_P-H_P, Y_P] = [-sy1*10, -sy0*10]` —— `-sy1*10` 是下边、`-sy0*10` 是上边 ✓

所以"Y 取反"只是 `-sy0*10` 这一项的负号在视觉上把 y 翻正。

## 顶视图（A 面）的差异

A 面 X 不镜像（或镜像方向相反），映射为 `sx0 = X_off - mx0*3.937; sx1 = X_off - mx1*3.937`
（即交换 mx0/mx1 的使用）。Y 同底视图。顶/底层丝印在编辑器里会自动再镜像一次以"从对应面看正"，
所以**落点坐标用上面的公式即可，镜像交给 `create` 与图层的固有行为**——验证靠 B8 的 IoU 回读，
不要凭截图猜。

## 回读栅格化（验证用，设计帧 20px/mm）

把 `get()` 的复杂多边形点 `(x,y)`（0.1mil）投回设计帧像素 `(px,py)`（1820×1200 @20px/mm）：

```python
px = (358.2677 - x) / 3.937 * 20
py = (y + 236.2205) / 3.937 * 20
```

逐子路径 `ImageDraw.polygon`（even-odd 异或合成多子路径），再与源 mask 算 IoU。
若设计稿渲染分辨率不是 20px/mm，把公式里的 `20` 换成对应 `px/mm` 即可。

## 丝印文字（silk-add）坐标

`pcb silk-add --x --y` 是 mil，原点与 `create` 同一框架。本项目实测：
- `HAND & MIC` 行墨迹 `x 8.05→30.50mm`、`y ≈ 52.8mm`（基线）
- 落点 `x_mil = 3582.677 - mm_x*39.37`，`y_mil = mm_y*39.37 - 2362.205`
- `mm_x=33.5 → x_mil≈2248`；`mm_y=52.8 → y_mil≈-284`

> 注意 `silk-add` 的 `(x,y)` 通常取锚点（基线左端），与 image 图元的"右/顶边缘"语义不同，
> 放之前先在 20px/mm 帧里量好该行末端，再换算。
